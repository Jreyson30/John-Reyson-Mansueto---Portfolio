# Reyson Mansueto — Portfolio Website

A responsive, single-page portfolio built with plain HTML, CSS, and JavaScript.

## Open in Visual Studio Code
1. Extract `reyson-portfolio.zip`.
2. In VS Code choose **File → Open Folder** and select `reyson-portfolio`.
3. Install the **Live Server** extension.
4. Right-click `index.html` → **Open with Live Server**.

## Files
- `index.html` — content and page structure
- `style.css` — visual design and responsive layouts
- `script.js` — navigation, filters, project popups, and copy-email interaction

## Publish it publicly for free (Netlify Drop)
1. Open https://app.netlify.com/drop
2. Sign in or create a free Netlify account.
3. Drag the extracted `reyson-portfolio` folder (the folder containing `index.html`) onto the page.
4. Netlify will publish it and provide a public `https://...netlify.app` link.
5. You can share that link with anyone. Keep the folder safe; you can update the site by deploying the updated folder again.

Alternative: GitHub Pages can also host this static website. Create a public repository, upload the three website files, then enable Pages in the repository's Settings.

## Before publishing
- Confirm the dates and role descriptions are accurate. The Workforce and Food Delivery dates overlap in the details supplied.
- The Facebook link currently opens a Facebook search for “Reyson Mansuto” because a direct profile URL was not supplied. Replace it with your exact profile URL when available.
- The portfolio workspace cards are interactive demonstrations. Replace/add real project images, links, and files as you wish.
- Add your own profile photo if you want one; the current About illustration is CSS artwork.
- Google Fonts load from the internet. The website still works if they are unavailable, using fallback fonts.

## Customize
Search in `index.html` for text you want to change. Update colors and layout in `style.css`. Update project popup content in `script.js`.
